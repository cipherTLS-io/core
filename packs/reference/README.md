# Reference pack boundary

No source pack has been built. Core M6.0 must resolve an exact upstream source and applicability
to the selected executable. M6.1 implements the immutable pack, refresh and offline behavior.

Keep original source bytes and notices, source URL/commit/hash, derived section identities,
applicable build matrix and last successful upstream check. Execution snapshots and candidate
updates are distinct. Never populate a compatibility matrix with an untested version range.
Contract: [companion design §3](../../docs/design/companion.md#3-reference-contract).
