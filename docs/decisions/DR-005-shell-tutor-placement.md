# DR-005 — Shell tutor placement

Status: open. Recorded: 2026-11-11, preserving the question in PRD v0.1.
System owner and prospective decider: veronaimars. No decision or consultation is claimed.

## Question

Which product should own future release-aware completion and standalone tutoring?

## Options and cost of being wrong

| Option | Cost of being wrong |
|---|---|
| Workshop, as the current proposal | May mix shell tooling and lesson delivery; bounded by a separate internal component |
| Terminal | May confuse operator evidence explanation with learner guidance |
| A new product | Adds a distribution and ownership boundary before its need is demonstrated |

The shared source index remains in core whichever product presents it. Decide after the first
learning/inspection journey establishes the audience need. Workshop M4 is direction while this
record is open; it does not authorize implementing a new product or changing the core contract.
